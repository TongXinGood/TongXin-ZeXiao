数据结构：栈和队列

数据结构2026-10
  • 栈：后进先出（LIFO），只在栈顶插入和删除；典型应用是括号匹配、表达式求值、函数调用。
  • 队列：先进先出（FIFO），队尾入队、队头出队；循环队列用取模避免“假溢出”。
  • 循环队列判满常用“牺牲一个单元”：(rear + 1) % maxSize == front。

计算机组成原理：Cache 映射方式

计组2026-10
  • 直接映射：每个主存块只能放到固定的一行，硬件简单，冲突多。
  • 全相联映射：可以放到任意一行，命中率高，比较电路成本高。
  • 组相联映射：先固定到某一组，组内任意放，是前两者的折中。

操作系统：常见进程调度算法

操作系统2026-10
  • 先来先服务（FCFS）：实现简单，对短作业不利。
  • 短作业优先（SJF）：平均等待时间最短，可能导致长作业“饥饿”。
  • 时间片轮转（RR）：公平、响应快，时间片太小会增加切换开销。

计算机网络：TCP 三次握手

计网2026-10

客户端发送 SYN → 服务器回复 SYN + ACK → 客户端再发送 ACK，连接建立。需要第三次握手，是为了防止已经失效的连接请求又传到服务器，导致服务器错误地建立连接。
